# Sprint 04 follow-up — 2026-11-12

Status: further implementation and local validation complete for the work below; **Sprint 04 remains partially accepted**. This report does not convert service probes into API-wide acceptance.

## Changes and compatible contracts

- Capture list projections prepare the latest manifest, at most 20 jobs per session, two selected tour revisions per job, review reasons and related media in SQL batches. Existing full responses remain supported. `GET properties/<id>/capture-sessions/?summary=true` adds a paginated compact projection without fetching manifest documents or job outputs. `GET property-captures/<id>/processing-jobs/` adds bounded job history and links to the existing details; POST retains its original behavior. Both read paths authorize ownership before counting or paging.
- Advertising placement prepares exact captured/paid/fulfilled proof with one correlated selector, retaining payer, subject and media checks. Owner pages prepare invoice links once per page. Missing media still fails closed; readiness is not fabricated or cached.
- Transition and tender search execute outside shared transactions. Their bounded finalists are independently revalidated under ordered current-authority/source locks before publication. Duplicate workers publish once; interrupted commits remain recoverable. Transition runs retain a bounded input digest/version manifest rather than duplicating private search criteria. Migration 0098 makes the new field nullable for old-worker inserts during rollout; a historical model insert is tested against the forward schema. No existing database migration was executed.
- Shared probe tooling now records CPU, Python heap, rendered response bytes or explicitly labeled projection estimates, HTTP/storage calls and observed transaction spans. Unknown inspected-row counts remain null; no false candidate/lock budget is inferred from a constant query count.

One ordered run took 2.318 ms. No speculative index was added. This is not a global bound on all invoice history.
