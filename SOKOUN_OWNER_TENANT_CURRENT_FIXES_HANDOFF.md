## 4. Backend Management Command

To refresh or rebuild test fixtures idempotently in any environment, run:

```bash
# Basic run with output to terminal and fixtures.json
python manage.py prepare_owner_tenant_cycle_qa --output=fixtures.json

# Extended run with complete scenario breakdown
python manage.py prepare_owner_tenant_cycle_qa --output=fixtures.json --print-extended
```

**Idempotency Guarantee:**  
Re-running this command does not reset existing operations, overwrite financial ledgers, or create duplicate database entities. It verifies presence, ensures all verification flags (`is_active=True`, `is_verified=True`, `payout_ready=True`) are set, refreshes future availability slots, and restores the authentic banner artwork.

- **Canonical Route:** `POST /api/v1/auth/refresh/`

### OPEN-06: Never-Occupied Cancellation & First-Read Closure (GAP001)
- When a lease draft is cancelled before occupancy:
  - `occupancy_status == NOT_STARTED` waives physical handover inspection requirements.
  - Absence of financial obligations waives final settlement ledger locks.
  - Authoritative financial closure is evaluated on read in `lease_detail`.
  - The very first GET to `/api/v1/features/v1/leases/{id}/` returns `status: "closed"` and `occupancy_status: "not_started"`. Collection, detail, and Rental Center agree at `closed` simultaneously.

### OPEN-09: Rejection Reason Compatibility
- Visit rejection view accepts mobile enum:
  - `reason: "timing_not_suitable"`
  - Optional `custom_reason: "<arbitrary string>"`
- Status transitions immediately to `rejected` with recorded timestamp.

## 6. How Mobile Dev Should Run the Integration Tests

From the Flutter app root directory (`apps/sokoun_app`), execute:

```bash
# 1. Read-Only Cycle Checks
make ownerTenantCyclesLiveRead \
  FLUTTER=flutter \
  SOKOUN_CYCLES_PRIVATE_DIR=/path/to/private/dir \
  CYCLES_EVIDENCE_DIR=./test_evidence/read

# 2. Full End-to-End Scenario Runner
make ownerTenantCyclesLive \
  FLUTTER=flutter \
  SOKOUN_CYCLES_PRIVATE_DIR=/path/to/private/dir \
  CYCLES_EVIDENCE_DIR=./test_evidence/scenario
```

### Build Flags Guidance
- Ensure `SOKOUN_BYPASS_VERIFICATION=false` to test authentic server permission decisions.
- Enable `SOKOUN_LEASE_SIGNING=true` to exercise the complete hosted signing flow in sandbox mode.
- Use `CYCLES_REUSE_SESSIONS=true` if executing with saved staging sessions.
