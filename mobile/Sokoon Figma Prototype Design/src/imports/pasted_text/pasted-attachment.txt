2. CREATE CLICKABLE PROTOTYPE CONNECTIONS
==================================================

Make all important buttons, tabs, icons, and CTAs clickable.

Use prototype arrows and interactions.

General interaction rules:
- Primary buttons should go to the next logical screen.
- Back buttons should go to the previous screen.
- Bottom navigation tabs should navigate to the correct tab screen.
- Menu items should open their relevant screens.
- Filter buttons should open filter bottom sheets as overlays.
- More buttons should open action bottom sheets.
- Modals and bottom sheets should appear as overlays.
- Cancel / close buttons should dismiss overlays.
- Success actions should navigate to confirmation screens or show success states.
- Error / rejected states should link to correction or re-upload screens.
- If a button has no final screen yet, create a simple placeholder state called “Coming Soon / Under Construction” instead of leaving it dead.

Use smart animate where suitable, especially for:
- Bottom sheets
- Modals
- Save/favorite interaction
- Tab switching
- Success states
- Loading to loaded states
